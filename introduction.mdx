## Welcome to ACM at CSUF

ACM at CSUF ([acmcsuf.com](https://acmcsuf.com)) is the official website for the Association for Computing Machinery chapter at California State University, Fullerton. The site serves as a hub for students to discover events, explore learning paths, meet the team, and engage with the broader ACM community.

The site is built with [SvelteKit](https://kit.svelte.dev/) and deployed on [Cloudflare Workers](https://workers.cloudflare.com/), making it fast, lightweight, and easy to contribute to.

## Tech stack

| Technology | Purpose |
|---|---|
| [SvelteKit](https://kit.svelte.dev/) | Full-stack web framework |
| [TypeScript](https://www.typescriptlang.org/) | Type-safe JavaScript |
| [Cloudflare Workers](https://workers.cloudflare.com/) | Hosting and deployment |
| [Wrangler](https://developers.cloudflare.com/workers/wrangler/) | Deployment CLI |
| [Vite](https://vitejs.dev/) | Build tooling |
| [Vitest](https://vitest.dev/) | Unit testing |
| [Google Calendar API](https://developers.google.com/calendar) | Events data |
| [GitHub Discussions](https://docs.github.com/en/discussions) | Blog posts / newsletter |
