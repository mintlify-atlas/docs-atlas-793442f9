acmcsuf.com is an open source project. Anyone can contribute — bug fixes, new features, content updates, and data changes are all welcome. CSUF students are especially encouraged to get involved.

## Code of conduct

All contributors are expected to follow the [Contributor Covenant Code of Conduct](https://github.com/acmcsufoss/acmcsuf.com/blob/main/CODE_OF_CONDUCT.md). The short version:

**Expected behavior:**
- Demonstrate empathy and kindness toward other people
- Be respectful of differing opinions, viewpoints, and experiences
- Give and gracefully accept constructive feedback
- Accept responsibility and apologize when mistakes affect others

**Unacceptable behavior:**
- Sexualized language, imagery, or unwanted advances
- Trolling, insults, derogatory comments, or personal attacks
- Public or private harassment
- Publishing others' private information without permission

Report violations to [contact@acmcsuf.com](mailto:contact@acmcsuf.com). Community leaders will review and respond promptly.

## Types of contributions

<CardGroup cols={2}>
  <Card title="Bug fixes" icon="bug">
    Found something broken? Open a bug report using the [Bug Report template](https://github.com/acmcsufoss/acmcsuf.com/issues/new?template=bug_report.yaml) and submit a fix.
  </Card>
  <Card title="New features" icon="sparkles">
    Have an idea? Open a [Feature Request](https://github.com/acmcsufoss/acmcsuf.com/issues/new?template=feature_request.yaml) and discuss it before building.
  </Card>
  <Card title="Content updates" icon="pencil">
    Blog posts live in GitHub Discussions under the [Newsletter category](https://github.com/acmcsufoss/acmcsuf.com/discussions/categories/newsletter). Create or edit discussions to add or update posts.
  </Card>
  <Card title="Data updates" icon="database">
    Officer profiles are stored in `src/lib/public/board/data/officers.json`. Shortlinks are in `src/lib/public/links/links.json`. Edit these files directly in a PR.
  </Card>
</CardGroup>

## Finding issues to work on

The best place to start is the [Good First Issue](https://github.com/acmcsufoss/acmcsuf.com/issues?q=is%3Aopen+is%3Aissue+label%3A%22good+first+issue%22) label. These issues are scoped to be approachable for first-time contributors.

Once you find an issue you want to work on, assign yourself to it or leave a comment asking to be assigned.

<Tip>
  If this is your first time contributing to an open source project, check out [acmcsuf.com/1st/](https://acmcsuf.com/1st/) for a walkthrough.
</Tip>
