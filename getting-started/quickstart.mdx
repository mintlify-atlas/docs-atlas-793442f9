This guide covers the fastest path to a running local development environment. For a full walkthrough including environment variables and all available scripts, see the [Local Setup](/getting-started/local-setup) guide.

## Prerequisites

Before you begin, make sure you have the following installed:

- **Node.js** `>=22.0.0` — [Download from nodejs.org](https://nodejs.org/en/download/)
- **npm** `>=10.5.1` — Bundled with Node.js
- **Git** — [Download from git-scm.com](https://git-scm.com/downloads)

## Steps

<Steps>
  <Step title="Clone the repository">
    Clone the acmcsuf.com repository to your local machine:

    ```bash
    git clone https://github.com/acmcsufoss/acmcsuf.com.git
    cd acmcsuf.com
    ```

    <Note>
      If you plan to contribute, fork the repository first and clone your fork instead. See [Local Setup](/getting-started/local-setup) for details.
    </Note>
  </Step>

  <Step title="Install dependencies">
    Install the project's dependencies using npm:

    ```bash
    npm install
    ```
  </Step>

  <Step title="Start the development server">
    Spin up the local development server:

    ```bash
    npm run dev
    ```

    The server will start and automatically reload whenever you make changes to the source code.
  </Step>

  <Step title="Open the site in your browser">
    Navigate to [http://localhost:5173/](http://localhost:5173/) in your web browser. You should see a local copy of the acmcsuf.com website.
  </Step>
</Steps>
