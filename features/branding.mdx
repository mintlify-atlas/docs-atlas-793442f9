The Branding page at `acmcsuf.com/branding` is a central resource for ACM at CSUF's visual identity. It provides logos and official brand colors for each team, available in SVG and PNG formats.

## What it includes

For each team, the branding page shows:

- **Team logo** — available to download as SVG and PNG
- **Team color** — the official color name, hex value, and RGB value

## How to use the page

<Steps>
  <Step title="Navigate to the branding page">
    Go to `acmcsuf.com/branding`.
  </Step>
  <Step title="Find your team's section">
    Each team has its own section showing the team logo and brand color swatch.
  </Step>
  <Step title="Download the logo">
    Use the SVG or PNG download links provided under each team logo.
  </Step>
  <Step title="Reference the color values">
    Copy the hex or RGB value from the color swatch to use in designs or code.
  </Step>
</Steps>

<Tip>
  The global CSS variables for these colors are defined in `/global.css`, which is also linked from the bottom of the branding page.
</Tip>

## Data structure

Branding data is defined in `src/routes/(site)/branding/data.ts` as a static array satisfying the `Branding` interface from `src/lib/public/branding/branding.ts`:

```typescript
export interface Branding {
  title: string;
  description: string;
  teamLogo: TeamLogo;
  teamColor: TeamColor;
}

export interface TeamLogo {
  image: string;
  alt: string;
  title: string;
  svg: string;
  png: string;
}

export interface TeamColor {
  name: string;
  hex: string;
  rgb: string;
}
```

## Adding or updating branding (contributors)

To add a new team or update an existing team's branding:

<Steps>
  <Step title="Add the logo assets">
    Place the SVG and PNG logos in `static/assets/` following the `{team-id}-logo.svg` naming convention.
  </Step>
  <Step title="Update data.ts">
    Add or update an entry in `src/routes/(site)/branding/data.ts` with the team's title, description, logo paths, and color values.
  </Step>
  <Step title="Verify on the branding page">
    Run `npm run dev` and navigate to `/branding` to confirm the logo and color swatch appear correctly.
  </Step>
</Steps>
